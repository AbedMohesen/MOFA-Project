# 🇵🇸 البوابة الإلكترونية لوزارة الخارجية والمغتربين - دولة فلسطين

### Palestinian Ministry of Foreign Affairs and Expatriates Portal

بوابة إلكترونية متكاملة وعصرية تمثل الموقع الرسمي لوزارة الخارجية والمغتربين الفلسطينية. تم بناء المشروع بالكامل باستخدام **Vanilla JavaScript** و **Tailwind CSS v4**، مع التركيز على أعلى معايير الأداء والسرعة، تجربة مستخدم عربية أصيلة (RTL First)، وتصميم حكومي مؤسسي فائق الاحترافية.

---

## 🌟 أبرز المميزات (Key Features)

### 1. 🚨 شريط الأخبار العاجلة التفاعلي (Interactive Breaking News Ticker)

- شريط إخباري متحرك أعلى الصفحة الرئيسية يعرض أحدث البيانات السياسية والدبلوماسية العاجلة.
- مؤشر نبضي حي (`Ping Animation`) لجذب الانتباه.
- تحكم يدوي بالأسهم (السابق / التالي) مع إيقاف مؤقت ذكي عند تمرير المؤشر (Pause on Hover) ودوران تلقائي ناعم.

### 2. 📰 سلايدر رئيسي ذكي ومصغرات تفاعلية (Smart Carousel & Thumbnails)

- سلايدر أخبار رئيسي مع تدرج لوني سينمائي لقراءة مثالية للعناوين والتفاصيل.
- شريط مصغرات أسفل السلايدر يوضح الشريحة النشطة بإطار ذهبي مميز، ويتيح التنقل المباشر بنقرة زر.
- مؤقت تشغيل تلقائي مع خاصية الإيقاف عند التمرير لتسهيل القراءة.

### 3. 🔍 محرك بحث وتصفية فورية (Real-Time Live Search)

- بحث فوري لحظي بدون إعادة تحميل الصفحة في:
  - **آخر الأخبار**: بحث متقدم في العنوان، التفاصيل، والتصنيف.
  - **ألبوم الصور والفيديو**: تصفية فورية وسريعة مع شاشة خلو نتائج أنيقة (Empty State).
  - **دليل الإصدارات والمعاملات**: تصفية فورية لصفوف الجدول بحسب نوع واسم المعاملة.
  - **الأسئلة الشائعة**: بحث تفاعلي يقوم بفتح السؤال المطابق تلقائياً.

### 4. 🔲 خيارات عرض مرنة (Grid & List View Switcher)

- إمكانية التبديل الفوري بين العرض الشبكي (Grid View) والعرض التفصيلي (List View) في صفحات الأخبار وألبومات الصور والفيديو، مع الحفاظ على النتائج المصفاة.

### 5. ⚡ بنية برمجية فائقة السرعة مع تخزين مؤقت (In-Memory Caching)

- استرجاع البيانات بصيغة JSON من خلال دالة تخزين مؤقت تمنع تكرار طلبات الشبكة (Zero Redundant Network Requests) مما يمنح تجربة تصفح فورية (Instant UX).

### 6. 📱 تجاوب كامل مع كافة الشاشات (100% Fully Responsive)

- دعم كامل لجميع أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات العريضة).
- شريط تنقل سفلي وقائمة منسدلة (Mobile Drawer / Hamburger Menu) مهيأة بتقنيات إمكانية الوصول (`Aria-expanded`).

### 7. 🎨 هوية بصرية وخط عربي معتمد (Typography & Institutional Theme)

- اعتماد خط Google Fonts العربي الرائد **Cairo** بجميع أوزانه.
- لوحة ألوان رسمية متناسقة مستوحاة من العلم الفلسطيني وألوان السلك الدبلوماسي (الذهبي الملكي، الأسود الفاحم، والرمادي المريح).

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية                       | الاستخدام                                                                  |
| :---------------------------- | :------------------------------------------------------------------------- |
| **HTML5 (Semantic)**          | هيكلية الصفحات وفق أفضل ممارسات SEO والوصولية                              |
| **Tailwind CSS v4**           | أحدث إصدار من إطار عمل التنسيق مع معالجة فائقة السرعة (`@tailwindcss/cli`) |
| **Vanilla JavaScript (ES6+)** | برمجة تفاعلية نقية خالية من المكتبات الثقيلة                               |
| **Font Awesome v6.5.1**       | أيقونات موحدة ومتجاوبة                                                     |
| **AOS (Animate On Scroll)**   | تأثيرات ظهور انسيابية عند التمرير                                          |
| **JSON Data API**             | مصدر بيانات الأخبار والمعاملات                                             |

## 🚀 التشغيل والتطوير محلياً (Getting Started)

### المتطلبات المسبقة:

- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the Repository)**:

   ```bash
   git clone https://github.com/your-username/mofa-project.git
   cd mofa-project
   ```

2. **تثبيت الحزم (Install Dependencies)**:

   ```bash
   npm install
   ```

3. **وضع التطوير والمراقبة الحية (Development Watch Mode)**:

   ```bash
   npm run dev
   ```

4. **بناء النسخة الإنتاجية (Production Build)**:

   ```bash
   npm run build
   ```

   _يقوم هذا الأمر بضغط ملف CSS وتقليص حجمه لأقصى سرعة ممكنة._

5. **فتح الموقع**:
   - قم بفتح ملف `index.html` في أي متصفح حديث، أو استخدم إضافة مثل `Live Server` في VS Code.
